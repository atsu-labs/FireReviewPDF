# 建築図面注釈・計測ソフトウェア 取扱説明書 (FireReviewPDF)

本ソフトウェアは、既存のPDF図面を背景として読み込み、その上に高精度な距離計測、面積計算、注釈（テキスト・図形・雲マーク・マーカー・凡例・円弧）の追加・編集を行うための先進的なデスクトップアプリケーションです。

---

## 1. 主な機能

### A. ファイル操作・プロジェクト管理
* **PDFインポート (`Ctrl + O`):** 図面PDFを背景として読み込みます（複数ページ対応、本文解像度 150 DPI / サムネイル 30 DPI）。メニューバーまたはツールバー左端のクイックアクションボタンから実行できます。
* **背景差し替え:** 既に描画した注釈データを維持したまま、背景のPDFファイルのみを更新します。
* **プロジェクト保存/読込（上書き保存・名前を付けて保存）:**
  * 編集中のアノテーションデータ、ページごとのキャリブレーション（縮尺設定）、背景表示設定（濃淡・白黒）、色名辞書などをJSON形式（`.json`）で保存し、後から完全に再編集できます。
  * **上書き保存 (`Ctrl + S`):** 保存先パスが設定済みの場合はダイアログを表示せず即座に上書き保存します（未設定時は保存ダイアログを表示）。
  * **名前を付けて保存 (`Ctrl + Shift + S`):** 常に保存ダイアログを表示して新規パスへ保存します。初期ファイル名として既存プロジェクト名または背景PDF名（`.json`）が自動提案されます。
  * **背景PDFの再選択フォールバック:** プロジェクト読込（`Ctrl + L`）時に背景PDFが見つからない、または破損している場合は、代替PDFを選択するダイアログを表示して安全に復旧できます。
* **未保存変更の検知と保護:**
  * 編集による未保存の変更（ダーティ状態）がある場合、ウィンドウタイトルのファイル名末尾に `*` マークを表示します。
  * アプリ終了時や新規PDF・別プロジェクトの読み込み時に未保存の変更がある場合、保存確認ダイアログを表示して作業データの誤消失を防止します。
* **PDF書き出し (`Ctrl + E`):**
  * **書き出し設定ダイアログ:** 出力対象ページの選択（「すべてのページ」または「注釈があるページのみ」）および背景図面の濃淡設定の反映有無を選択して出力できます。
  * **高精度合成と安全な保存:** 回転情報を持つPDFページ、DPI換算に応じた線幅・マーカーサイズ補正、フォントメトリクス基準のテキスト配置により、画面表示と出力PDFの見た目を忠実に一致させます。また、出力先のファイルロック事前検知や一時ファイル経由のアトミック保存に対応し、元PDFへの安全な上書き保存も可能です。

### B. 計測・描画ツール
* **キャリブレーション（縮尺設定）:** 
  * **2点指定方式:** 図面上の既知の2点間をクリックし、実寸法を入力することで縮尺（1pxあたりのmm数）を定義。
  * **縮尺指定方式:** 「1/50」「1/100」などの縮尺比率を直接指定してキャリブレーション可能。
  * **ページ別・全ページ一括管理:** キャリブレーションデータはページごとに個別に保持・管理できるほか、全ページへ一括適用することも可能です。
* **距離計測 (直線/折れ線) (`L` キー):** 直線または折れ線（ポリライン）を描画し、プロパティパネルの「📐 計算する」ボタンから実寸法（m または mm）を算出してラベル表示します。
  * *Shiftキーを押しながらドラッグ・クリックすることで、15度単位の角度スナップに対応。*
  * 折れ線ツールの始点・終点には、矢印（Arrow）や丸（Circle）などのマーカーを設定可能。
* **面積計測 (矩形/多角形) (`R` キー):** 多角形で囲んだ領域を描画し、「📐 計算する」ボタンから面積（m² または mm²）を算出してラベル表示します。
  * *右クリックで形状を確定します。*
* **円描画 (半径指定対応) (`C` キー):** クリック＆ドラッグで自由な大きさの円を描画するほか、キャリブレーション済みであればツールオプションバーで半径の実寸法（m または mm、現在の表示単位に自動同期）を数値指定し、キャンバス上をクリックして正確な半径の円を作図することも可能。中心点に丸・十字・バツ等の中心マーカーを設定可能。
* **円弧 (Arc) ツール:** 中心点からドラッグして半径と向きを決定し、指定した角度幅（スパン）の円弧を描画。中心マーカーや半径補助線の表示にも対応。
* **雲マーク（クラウド注釈）ツール (`K` キー):** マウスドラッグで矩形領域を指定し、建築・設備図面の変更箇所や指摘事項を強調する雲マーク（大小交互のモコモコとした外向き円弧枠）を直感的に描画できます。
  * *`Shift` キーを押しながらドラッグすることで正方形に制約可能。*
  * *通常の計測図形とは独立した専用デフォルトスタイル（初期値：赤線 `#ff0000`・塗りなし・線幅 2px）を保持し、作成後は頂点編集によって自由な多角形雲マークへ変形可能です。*
* **マーカー配置ツール (`M` キー):** 「四角形（スクエア）」または「チェックマーク（✓）」スタイルのマーカーを10色のパレットから選んで図面上にワンクリックで配置できます。
* **凡例 (Legend) 作成ツール:** ページ内に配置されたマーカーのスタイルと色をリアルタイムに自動集計し、図面上に移動可能な「凡例テーブル」として動的に生成・配置します。

### C. オブジェクト編集・カスタマイズ
* **選択・移動・複数選択 (`V` キー):** 配置済みのオブジェクトを選択し、ドラッグで位置を微調整できます。`Shift`（または `Ctrl`）＋クリックでの追加・除外トグル選択、背景ドラッグによる矩形範囲選択（ラバーバンド）、`Shift`＋ドラッグでの範囲追加、`Alt`＋ドラッグでの範囲除外に対応しています。複数選択したオブジェクトは相対位置を保ったまま一括でドラッグ移動できるほか、`Delete` / `Backspace` キー・右クリックメニュー・プロパティパネルから一括削除できます。
* **アンドゥ・リドゥ（元に戻す / やり直す） (`Ctrl + Z` / `Ctrl + Y`):** 注釈の追加、削除、移動、頂点編集、ラベル位置移動、インラインテキスト編集、計測値計算、および右パネルからの属性変更（スライダー等の連続変更の自動マージ対応）を取り消し・やり直しできます。別ページで行った操作を取り消す際は自動的に対象ページへ遷移します。
* **ノード（頂点）編集機能:** 折れ線、多角形、雲マーク、または引き出し線付きテキストを選択してノード編集モードに入ると、個々の頂点をドラッグして形状を後から自由に変更できます（ダブルクリックや右クリックメニューで頂点削除、辺上でダブルクリックや右クリックメニューで頂点追加も可能）。
* **オンデマンド計測と自動再計算:** 図形（折れ線・多角形・円・円弧）はプロパティパネルの「📐 計算する」を実行した対象のみ計算結果ラベルを表示します。一度計算を実行した図形は、その後の頂点編集・キャリブレーション変更・単位変更時に自動で再計算されます。
* **計算結果ラベルの個別移動:** 距離・面積・半径などの測定結果ラベルを、オブジェクトとは独立してドラッグ移動し、最適な位置に配置できます。形状を編集して再計算が行われた場合でも、指定したラベルのオフセット位置は自動で維持されます。また、ホバー時に対応するオブジェクトとの関係を示すガイド線が表示されます。
* **テキスト注釈の拡張 (`T` キー):** 任意の場所にテキストを追加できます（視認性とPDF出力互換性に優れた「BIZ UDゴシック」フォントに統一）。
  * テキストの「囲み枠（Border）」表示（色・太さ変更可）に対応。
  * テキストから対象物を指し示す「引き出し線（Leader Line）」を追加し、テキスト移動に追従させることが可能。
* **ポップアップ型カラーパレットと線・塗り色の連動:**
  * ツールオプションバーおよびプロパティパネルの色プレビュー枠をクリックすると、標準12色パレット・最近使った色（履歴）・塗りなし・カスタム色選択を備えたポップアップパレットが開きます。
  * 「線と同色」連動チェックを有効にすると、線の色を変更した際に塗りの色も自動で同色に同期します（塗りの色を個別に変更・塗りなしにした場合は自動で連動解除）。
* **プロパティパネル (右側):** 選択したオブジェクトの種類に応じて必要な設定項目のみを動的に表示します（スクロール表示対応）。
  * テキスト内容、文字サイズ（図面固定スケール）。
  * 線の色・塗りの色（左右並列配置・連動対応）、線の太さ、線の不透明度、塗りの不透明度。
  * 各種装飾（始点/終点/中心マーカー、引き出し線、囲み枠、円弧スパン角、マーカー種類・色・不透明度など）。
  * 計測値の算出（「📐 計算する」ボタン）、頂点編集モードの切り替え、要素の削除。
* **オブジェクトナビゲーター (左側):**
  * **ページサムネイルと背景図面調整:** ページサムネイル一覧（選択ページのハイライト同期対応）に加え、背景図面の**濃度（不透明度 10%〜100%）スライダー**および**白黒（グレースケール）表示切り替え**を備え、図面を淡色化・白黒化して注釈を際立たせることができます。
  * **オブジェクト一覧と自動センタリング:** ページ内のオブジェクト一覧から項目をクリックして選択すると、現在のズーム倍率を維持したまま対象のオブジェクトが画面中央に自動スクロール（センタリング）されます。
  * **マーカー集計と色名編集:** パネル下部でマーカーの集計（色・スタイル別）を確認でき、色ごとに「任意の名称（例：消火器、スプリンクラーなど）」をページ別に編集・定義して凡例テーブルへリアルタイムに反映できます。

### D. 操作性・ビュー制御・ショートカット
* **ズーム・ページ表示制御:**
  * ツールバーのコンボボックス、マウスホイール、またはメニューバーの「表示」メニューから拡大（`Ctrl + +`）・縮小（`Ctrl + -`）を行えます。
  * **高倍率ズーム時の背景PDF動的再レンダリング:** 拡大表示時（150 DPI相当を超えるズーム時）は、ズームやパン操作の停止後（200msデバウンス）に現在の表示領域（＋周囲25%のスクロール余白）を最大 **600 DPI（400%相当）** で動的にクリップ再ラスタライズして重ね合わせ表示します。大判図面でもメモリを圧迫せず、細かな文字や記号をボケのない鮮明な画質で確認できます（等倍以下への縮小時は即座に150 DPIベース画像へ復帰）。
  * **ページ全体を表示 (`Ctrl + 0`):** ページ全体がキャンバスに収まるよう自動調整（フィット）します（ページ切替時にも自動適用）。
  * **物理DPIベースの100%実寸大表示 (`Ctrl + 1`):** ディスプレイの物理DPI情報を自動取得し、印刷時のサイズと画面上の表示寸法が一致する「実寸大表示（100%）」に瞬時に切り替えます。
  * **ページ移動 (`PageUp` / `PageDown`):** 前後のページへ素早く移動できます。
* **軽快なキーボード＆マウス操作:**
  * **アンドゥ・リドゥ (`Ctrl + Z` / `Ctrl + Y` / `Ctrl + Shift + Z`):** メニューバーの「編集」メニューまたはショートカットキーから直前の注釈操作を素早く取り消し・やり直しできます。
  * **シングルキーツール切替:** 選択 (`V`)、パン (`H`)、直線/折れ線 (`L`)、矩形/多角形 (`R`)、円 (`C`)、雲マーク (`K`)、テキスト (`T`)、マーカー (`M`) をワンキーで切り替え可能。
  * **スペースキーによる一時パン:** どの描画ツールを選択していても、`Space` キーを押している間は一時的に手のひら（パン）モードに切り替わり、ドラッグで画面を自由にスクロールできます。
  * **`Esc` キーによる多段階キャンセル:** 作図中のプレビュー破棄、頂点編集やテキスト編集の完了、選択解除、選択ツールへの復帰を段階的に行えます。
* **スケール・用紙サイズ・座標表示:** ツールバー右側に現在のページのキャリブレーション状態（例：`スケール: 1/50`）と用紙サイズ（例：`PDFサイズ: A3` / `PDFサイズ: 210×297 mm`）を自動判定して表示し、下部ステータスバーにカーソル座標を表示します。
* **mm/m 表示単位の切り替え:** メニューバーの「設定」→「環境設定...」（`Ctrl + ,`）から、表示単位を「m」と「mm」の間で自在に変更でき、ツールオプションバーの半径入力単位および計算済みアノテーションの表示が自動で再計算・再フォーマットされます。

## 2. セットアップと実行方法

### 必要環境
* Python 3.10 以上
* 依存ライブラリ: `PySide6`, `PyMuPDF` (fitz), `qtawesome`

### インストール
```powershell
# 実行に必要なパッケージのインストール
pip install -r requirements.txt

# 開発・テスト用パッケージのインストール
pip install -r requirements-dev.txt
```

### 実行
```powershell
python src/main.py
```

### テストの実行
単体テストには `pytest` を使用します（`py -m pytest` で実行してください）。

```powershell
py -m pytest
```

### Windows アプリ（EXE）のビルド
PyInstaller を使用して、単一実行可能ファイル（Onefile 形式）を作成できます。

1. **PyInstaller のインストール:**
   ```powershell
   pip install pyinstaller
   ```
2. **ビルドの実行:**
   ```powershell
   # 付属のビルドスクリプトを実行
   .\build_exe.ps1
   
   # または直接 spec ファイルを指定してビルド
   pyinstaller FireReviewPDF.spec --clean
   ```
3. ビルドが完了すると、`dist/FireReviewPDF.exe` が生成されます。コンソール画面なしのスタンドアロン Windows アプリケーションとして直接起動できます。

## 3. 基本的な操作フロー

1. **図面を開く・背景を調整する:**
   * ツールバー左端の「PDF図面を開く」アイコン（またはメニューバー「ファイル」→「PDF図面を開く」/ `Ctrl + O`）から背景となるPDF図面を選択します。ツールバー右側に自動的に用紙サイズ（例：`PDFサイズ: A3`）が表示されます。
   * 図面の線が濃くて注釈が見づらい場合は、左側ナビゲーターパネルの「背景図面の設定」で濃度スライダーを下げて淡色化したり、「白黒表示」に切り替えたりできます。

2. **縮尺を設定する (キャリブレーション):**
   * メニューバーの「設定」→「環境設定...」（または `Ctrl + ,`）を開き、「単位」および「縮尺」を設定します。
   * **既知の比率を使う場合:** 縮尺比率（例：`1/50` や `1/100`）を設定して適用します。
   * **図面上の実寸から合わせる場合:** 「図面からキャリブレーション」ボタンを押し、図面上のスケールバーなどの既知の2点をクリックして、ポップアップに実寸法（m または mm）を入力します。
   * ツールバー右側の「スケール」インジケータが「スケール: 1/50」のように有効化されます。

3. **計測・描画を行う:**
   ツールバー（またはショートカットキー）から任意のツールを選択し、図面上に書き込みます（「連続作成」チェックを入れると同じツールで連続して描画できます）。
   * **距離/折れ線 (`L`):** クリックで頂点を追加し、ダブルクリックまたは右クリックで確定。`Shift` キーで15度単位の角度スナップ。
   * **面積（矩形/多角形） (`R`):** クリックで多角形を描き、右クリックで形状を確定。
   * **円 (`C`) / 円弧:** ドラッグして描画。円の半径を数値指定する場合は、キャリブレーション後に上部のツールオプションバーで半径（m または mm）を入力し、図面上をクリックします。
   * **雲マーク (`K`):** 変更箇所や指摘エリアを対角ドラッグして矩形の雲マークを描画（`Shift` キーで正方形に制約）。作成後に「📐 頂点を編集」から頂点の移動・追加・削除を行い、任意の多角形雲マークに変形することも可能です。
   * **計測値の表示:** 描画した図形（折れ線・多角形・円・円弧）に実寸法や面積のラベルを表示したい場合は、対象を選択して右側プロパティパネルの「📐 計算する」ボタンを押します。
   * **テキスト (`T`):** クリックして文字を入力。選択後、プロパティパネルから「枠線で囲む」や「引き出し線を表示」の有無・色・太さを設定可能。
   * **マーカー (`M`):** ツールオプションバーで種類（四角形/チェックマーク）・色・不透明度を選択し、図面をクリックして配置。

4. **凡例を配置・集計する:**
   * 図面上に1つ以上マーカーを配置すると、ツールバーの凡例ツール（Legend）が有効になります。
   * 凡例ツールを選択し、図面上の配置したい場所をクリックすると、自動集計された凡例テーブルが配置されます。
   * 左側のナビゲーターパネル下部の「マーカー集計」リストで、各色のテキスト入力欄に「消火器」などのカスタム名を入力すると、図面上の凡例テーブルの文字もリアルタイムに更新されます。

5. **微調整・編集する:**
   * 「選択」モード（`V` キー）に切り替え、オブジェクトを選択します（`Shift` / `Ctrl` クリックや背景の矩形ドラッグ、`Shift`＋ドラッグ追加、`Alt`＋ドラッグ除外による複数選択・一括移動・一括削除にも対応しています。左側ナビゲーターのオブジェクト一覧からクリックすると、対象オブジェクトが画面中央に自動センタリングされます）。
   * 右側のプロパティパネルで線の太さ、色（ポップアップパレット対応）、塗りつぶし、不透明度、マーカー装飾などを調整します。
   * 計算結果のテキストラベル部分をドラッグして、見やすい位置に個別移動できます。
   * 頂点位置や引き出し線の先端を微調整したい場合は、左側のナビゲーターパネルの「編集」ボタンまたは右側のプロパティパネルの「📐 頂点を編集」を有効にし、表示されたハンドルをドラッグします。
   * 誤って削除・移動・属性変更を行った場合は、`Ctrl + Z`（またはメニューバー「編集」→「元に戻す」）でいつでも元の状態に戻せます（`Ctrl + Y` でやり直し）。

6. **結果の保存と書き出し:**
   * 編集中の作業状態を保存する場合は、ツールバーの保存アイコンまたはメニューバー「ファイル」→「プロジェクトを保存」（`Ctrl + S`、2回目以降は即座に上書き保存）、「名前を付けて保存...」（`Ctrl + Shift + S`）を実行し、JSONファイルを保存します。
   * 成果物として印刷・共有用PDFを出力する場合は、「PDFを書き出し」（`Ctrl + E`）を実行し、書き出し設定ダイアログで出力ページ範囲（「すべてのページ」または「注釈があるページのみ」）と背景濃淡の反映有無を選択して出力します。

## 4. 技術仕様（開発者向け）

### アーキテクチャ
* **GUIフレームワーク:** PySide6 (Qt for Python)
  * `QGraphicsView` / `QGraphicsScene` を使用したスムーズなズーム・パン、白用紙下地（`paper_item`）による背景ウォッシュアウト表示、高精度な座標系管理。
  * 各種描画モードは **Stateパターン**（`BaseCanvasTool` を継承する各種ツールクラス）によってイベント管理を分離。
  * 注釈削除時はシーン全体の再構築を行わず差分削除（`remove_annotation`）を行うことで軽快な操作性を維持。
* **コントローラー層・サービス層による責務分離:**
  * **`MainWindow`:** UIコンポーネントとコントローラー/サービス層を統合するオーケストレーター。
  * **`CanvasController` & Commandパターン (`undo_commands.py`):** キャンバス上の描画完了イベント、注釈アイテムの生成・単一/複数選択（自動センタリング）・一括移動・一括削除、ナビゲーターおよびプロパティパネルとの画面同期を統括。`QUndoStack` および `QUndoCommand` 派生クラス（`AddCommand`, `RemoveCommand`, `MoveCommand`, `PropertyChangeCommand`, `BatchMoveCommand`, `BatchRemoveCommand`）によるUndo/Redo履歴管理と連続変更マージを制御。
  * **`ToolController`:** アクティブツールの切り替え、ツールオプションバーの設定値・線色と塗色の連動状態・ツール別デフォルトスタイル管理を担当。
  * **`DocumentManager`:** プロジェクトJSONおよびPDFのファイル読み書き、保存パス管理、未保存変更の追跡（ダーティフラグ管理・シグナル通知）をカプセル化。
  * **`MeasurementService`:** キャリブレーション値の計算、実寸法（距離・面積・半径）の算出、単位変換・表示フォーマット等のピュアな計算ロジックをGUIから完全分離。
* **アノテーションモデル:**
  * 基底クラス `BaseAnnotation` と図形固有の派生クラス（`CircleAnnotation`, `ArcAnnotation`, `CloudAnnotation`, `TextAnnotation` 等）によるポリモーフィズム設計。
  * `Annotation("type")` ファクトリおよび `Annotation.from_dict()` の動的ディスパッチによる後方互換性維持。
* **PDF処理エンジン:** PyMuPDF (fitz)
  * 本文表示用の150 DPIラスタライズ、高倍率ズーム時の表示領域クリップ高解像度ラスタライズ（最大600 DPI、専用LRUキャッシュ管理）、サムネイル用の30 DPI低解像度レンダリング、およびグレースケール（`fitz.csGRAY`）ラスタライズに対応。容量制限付きLRUキャッシュ（全体画像最大3ページ・クリップ画像最大6件）および `QImage` メモリ所有権の分離（`.copy()`）により高速描画と省メモリ・クラッシュ防止を両立。
  * **Strategy / Registryパターン**（`BasePdfRenderer` を継承する図形別専用レンダラー）による疎結合なPDF出力ロジック分離。
  * アノテーションフォントを「BIZ UDゴシック」に統一し、フォントメトリクス基準のベースライン・行送り補正、DPI換算の線幅・マーカー補正、ページ回転補正、背景淡色化マスク合成およびページ辞書へのRGB透過グループ（`/Group << /Type /Group /S /Transparency /CS /DeviceRGB >>`）明示設定により、キャンバス表示と出力PDFの完全一致・色くすみ防止を実現。
  * PDF出力時は書き込み権限・排他ロックの事前検証（`check_writable`）と一時ファイル経由のアトミック保存（`os.replace`）によりファイル破損を防止。
* **データ永続化仕様:** 
  * 座標系はPDFのピクセル座標（150 DPIベース）を基準に統一。
  * JSON保存時はページごとのスケールファクター、背景表示設定（`bg_opacity`, `bg_grayscale`）、注釈の幾何情報・計算状態（`is_calculated`）、テキスト装飾、凡例位置、マーカー集計用のローカル色名データを完全保持。
